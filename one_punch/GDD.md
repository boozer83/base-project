## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 엔드리스 러너 + 거리 판정 액션 |
| 타겟 | 10~30대, 캐주얼~미드코어 |
| 핵심 재미 | "벽이 코앞에 왔을 때 터치 → 완벽한 타이밍의 쾌감" |
| 플레이 시간 | 1판 1~3분 (스태미나 기반) |

---

## 2. 핵심 게임 루프

```
[로비] → 스태미나 소비(1) → [인게임]
            ↓
        캐릭터 자동 달리기
            ↓
        벽 등장 → 벽이 캐릭터를 향해 접근
            ↓
        플레이어 화면 터치
            ↓
        터치 순간 벽과 캐릭터 사이의 거리로 판정
            ↓
    [PERFECT / GREAT / GOOD] → 벽 파괴 → 계속 달리기 (콤보 +1)
    [MISS / 데미지 부족]     → HP 감소 → HP=0 → 게임오버
            ↓
    [게임오버] → 광고 보고 1회 부활 or 결과 화면
            ↓
        코인/경험치 획득 → 강화 → [로비]
```

## 3. 거리 기반 판정 시스템 ★ 핵심 변경

### 기본 개념

타이밍 바(UI 요소) 없음. 플레이어는 벽이 캐릭터에게 접근하는 것을 보고,
**적절한 거리에서 직접 화면을 터치**하여 판정을 만들어낸다.

```
[벽 등장]  ────────────────────────►  [캐릭터]
           멀다                   가깝다
           ↑                         ↑
         MISS                     PERFECT
```

### 판정 구간 (벽과 캐릭터 사이의 픽셀 거리 기준)

| 판정 | 거리 범위 | 데미지 배율 | 연출 |
|------|-----------|------------|------|
| 👊 **PERFECT** | 0 ~ 30px | 200% | 화면 흔들림 + 충격파 + 파편 폭발 |
| ✊ **GREAT** | 31 ~ 80px | 130% | 파편 튀김 + 균열 |
| 🤜 **GOOD** | 81 ~ 150px | 80% | 균열 |
| ❌ **MISS** | 150px 초과 / 미터치 | 0% | 캐릭터 피격 + HP 감소 |

> 벽이 캐릭터를 완전히 통과하면 자동 MISS 처리

### 거리 시각화 (힌트 UI)

타이밍 바는 없지만, 거리감을 체감할 수 있는 **간접 힌트**만 제공:

| 거리 | 힌트 |
|------|------|
| 벽이 화면 진입 시 | 배경 색상이 서서히 붉어짐 |
| GOOD 범위 진입 시 | 캐릭터 주먹이 발광 시작 (약하게) |
| GREAT 범위 진입 시 | 발광 강도 증가 + 미세 진동 |
| PERFECT 범위 진입 시 | 발광 최대 + 화면 테두리 섬광 |

> 숙련될수록 힌트 없이도 감각으로 PERFECT를 노릴 수 있어야 함

### 판정 거리 보정 (SPD 스탯 반영)

SPD 레벨이 높을수록 판정 범위가 넓어짐:

```
PERFECT 범위: 0 ~ (30 + SPD보정)px
GREAT   범위: ~ (80 + SPD보정)px
GOOD    범위: ~ (150 + SPD보정)px

SPD 보정값: SPD레벨 × 1.5px (최대 +45px @ Lv30)
```

### 벽 통과 자동 MISS

- 벽이 캐릭터 위치를 지나쳐 버리면 자동으로 MISS 처리
- 터치 없이 방치해도 동일하게 MISS

---

## 4. HP 시스템

- 캐릭터 기본 HP: 3칸 (하트)
- MISS 1회 = 하트 1개 감소
- 데미지 부족으로 벽 파괴 실패 = 즉시 게임오버
- PERFECT 5연속 = 하트 1개 회복 (최대치 초과 불가)

---

## 5. 콤보 시스템

```
콤보 1~9   : 데미지 보너스 없음
콤보 10~19 : 데미지 +10%
콤보 20~29 : 데미지 +20%
콤보 30+   : 데미지 +30% (최대)
MISS 발생  : 콤보 초기화
```

---

## 6. 벽 시스템

### 기본 벽 (Phase 1 — MVP)

| 벽 종류 | 구간 | HP | 속도 | 특이사항 |
|---------|------|----|------|----------|
| 🪵 나무벽 | Stage 1~10 | 100 | 느림 | 없음 |
| 🪨 돌벽 | Stage 11~25 | 300 | 보통 | 없음 |
| 🔩 철벽 | Stage 26~50 | 700 | 빠름 | 없음 |
| ⚙️ 강철벽 | Stage 51+ | 1500 | 매우 빠름 | 없음 |
| 💀 보스벽 | 10스테이지마다 | 5000 | 패턴 있음 | 속도 변칙 |

> 스테이지가 오를수록 벽의 접근 속도가 빨라지므로,
> 같은 PERFECT 거리를 맞추기가 점점 어려워짐

### 특수 벽 (Phase 2 이후)

| 특수 벽 | 설명 |
|---------|------|
| 멀티 히트 벽 | 여러 번 연속 터치 필요 (터치마다 거리 판정) |
| 이동 벽 | 좌우로 흔들리며 접근 (거리 판정 난이도 상승) |
| 분열 벽 | 파괴 시 2개로 쪼개져 재접근 |
| 가속 벽 | 접근 도중 속도가 갑자기 빨라짐 |

## 7. 캐릭터 시스템

### 기본 스탯

| 스탯 | 설명 |
|------|------|
| ATK | 벽에 주는 기본 데미지 |
| SPD | PERFECT/GREAT/GOOD 판정 거리 범위 보정 |
| COMBO | 연속 히트 시 추가 데미지 상승폭 |
| HP | 기본 하트 수 |

### 캐릭터 라인업

| 캐릭터 | 획득 방법 | 특성 |
|--------|-----------|------|
| 🥋 원펀남 | 기본 제공 | 균형형 |
| 🧙 마법사 | 스테이지 해금 | 스킬 게이지 빠름 |
| 🤖 사이보그 | 가챠 | ATK 특화, COMBO 약함 |
| 👹 괴물 | 가챠 | COMBO 특화, 스킬 없음 |
| 💫 전설 캐릭터 | 가챠 (SR) | 전체 스탯 최상급 + 전용 이펙트 |

---

## 8. 스킬 시스템

### 스킬 슬롯: 3개
- 인게임 하단에 스킬 버튼 3개 표시
- 스킬 게이지는 PERFECT/GREAT 히트 시 충전
- 발동: 스킬 버튼 탭 → 다음 펀치에 적용

| 스킬 | 효과 | 게이지 |
|------|------|--------|
| 💥 울트라 펀치 | 다음 펀치 데미지 500% | 100% |
| 🛡️ 오라 방어 | 다음 MISS 1회 무효화 | 80% |
| ⚡ 슬로우 타임 | 2초간 벽 속도 50% 감소 (판정 여유 증가) | 60% |
| 🔥 연속 펀치 | 자동 3연타 (GOOD 판정 자동 적용) | 80% |
| 🌪️ 폭풍 콤보 | 현재 콤보 수 × 2% 추가 데미지 | 70% |

## 9. 강화 & 성장 시스템

### 캐릭터 강화 (코인 소모)

```
ATK    Lv 1 ~ 50  (레벨당 코인 비용 지수 증가)
SPD    Lv 1 ~ 30  (판정 거리 범위 확장)
COMBO  Lv 1 ~ 30
HP     Lv 1 ~ 20
스킬   각 Lv 1 ~ 10
```

### 돌파 시스템
- 강화 Lv 10 / 20 / 30 마다 **돌파석** 필요
- 돌파석 획득처: 보스 클리어, 랭킹 보상, 젬 교환

### 장비 — 글러브

| 등급 | 획득 | 효과 |
|------|------|------|
| 일반 ⬜ | 코인 구매 | ATK +5% |
| 고급 🟦 | 코인 구매 | ATK +15% |
| 희귀 🟪 | 가챠 | ATK +30% + 보조 효과 1종 |
| 전설 🟨 | 가챠 SR | ATK +60% + 보조 효과 2종 |

## 10. 스태미나 시스템

```
최대 스태미나: 30
기본 회복: 5분당 1개 (자연 회복)
1판 소비: 1 스태미나
완전 회복: 젬 30개 or 광고 시청 3회 (하루 1회 한정)
스태미나 초과 보관: 불가 (30이 최대)
레벨업 보너스: 레벨 업 시 스태미나 즉시 전량 회복
```

## 11. 커뮤니티 시스템

### 전체 채팅 (Global Chat)
- 실시간 채팅 (WebSocket)
- 채팅 가능 조건: 닉네임 설정 완료 + Lv 3 이상 (스팸 방지)
- 필터링: 욕설/도배 자동 감지 → 경고 → 채팅 금지

```
[전체 채팅 UI]
┌─────────────────────────────┐
│ 🌍 전체 채팅                │
│─────────────────────────────│
│ [원펀왕] Stage 47 클리어!   │
│ [마법사킹] 보스 너무 어렵;;  │
│ [달리기신] 콤보 150 달성 ㅋ  │
│─────────────────────────────│
│ [입력창]              [전송] │
└─────────────────────────────┘
```

### 귓말 (Whisper / DM)
- 특정 유저 닉네임 탭 → 귓말 메뉴
- 1:1 개인 채팅 / 귓말 수신 거부 설정 가능

### 친구 시스템
- 친구 신청 / 수락 / 거절
- 친구 목록에서 바로 귓말 가능
- 친구 스테이지 기록 비교
- 친구 온라인 상태 표시

### 신고 & 제재
- 유저 신고: 욕설, 사기, 도배
- 신고 누적 → 자동 채팅 제한 (24h / 7d / 영구)
- 관리자 패널 (백엔드 어드민)

## 12. 과금 & 수익화 모델

### 재화 구조

```
⭐ 코인   → 무과금 주요 재화, 강화/상점에 사용
💎 젬     → 프리미엄 재화, 현금 or 광고로 획득
🎫 가챠권 → 캐릭터/장비 뽑기 (젬 교환 또는 직접 판매)
🪨 돌파석 → 강화 돌파에 필요한 재료
```

### 가챠
- 1회 뽑기: 젬 100 or 가챠권 1장
- 10연 뽑기: 젬 900 (10% 할인)
- **천장**: 100번 내 SR(전설) 1개 보장
- **픽업 이벤트**: 특정 캐릭터 확률 2배 (2주마다)
- 무과금 배려: 주간 무료 1회 보장

### 배틀 패스 (월정액)

```
[무료 패스]  → 기본 코인/아이템 보상
[프리미엄 패스] 9,900원/월
  → 패스 전용 캐릭터 스킨
  → 코인 획득량 2배
  → 전용 펀치 이펙트
  → 매일 젬 10개 지급
  → 패스 전용 칭호
```

### 광고 (무과금 친화)

| 광고 시청 | 보상 |
|-----------|------|
| 게임오버 시 | 1회 부활 |
| 스테이지 클리어 후 | 코인 2배 |
| 하루 5회 | 젬 10개 |
| 스태미나 부족 시 | 스태미나 5 회복 (하루 1회) |

### 상점 직구

| 상품 | 가격 | 내용 |
|------|------|------|
| 젬 소량팩 | 1,100원 | 젬 60 |
| 젬 중량팩 | 5,500원 | 젬 320 (+20 보너스) |
| 젬 대량팩 | 11,000원 | 젬 700 (+100 보너스) |
| 스타터팩 | 3,300원 | SR 캐릭터 1 + 젬 100 (최초 1회) |
| 스태미나팩 | 1,100원 | 스태미나 MAX 회복 x5 묶음 |

## 13. 콘텐츠 & 재방문 유도

### 일일 미션 (Daily)

```
✅ 오늘 3판 플레이           → 코인 500
✅ PERFECT 20회 달성          → 코인 300 + 젬 5
✅ 스테이지 5개 클리어         → 젬 10
✅ 전체 채팅 1회 참여          → 코인 200
```

### 출석 체크
- 7일 연속 출석 → SR 가챠권 1장
- 30일 연속 → 전설 캐릭터 1종 선택 지급

### 랭킹

| 랭킹 종류 | 기준 | 초기화 |
|-----------|------|--------|
| 스테이지 랭킹 | 최고 클리어 스테이지 | 시즌마다 |
| 콤보 랭킹 | 최대 콤보 수 | 주간 |
| 거리 랭킹 | 누적 달린 거리 | 월간 |

### 시즌 시스템
- **4주마다 시즌 교체**
- 시즌 전용 벽 디자인, 배경, 스킨
- 시즌 랭킹 보상: 1~10위 전설 가챠권, 11~100위 SR 가챠권

### 업적

```
🏅 "첫 번째 벽"      → 첫 벽 파괴
🏅 "퍼펙트 머신"     → PERFECT 1000회
🏅 "마라토너"        → 누적 거리 1000km
🏅 "채팅왕"          → 전체 채팅 100회
🏅 "친화력 갑"       → 친구 10명
🏅 "콤보 마스터"     → 콤보 50 달성
```

## 14. UI/UX 구조

```
스플래시 (로고 + 로딩)
    ↓
메인 로비
├── 캐릭터 뷰 (중앙, 탭하면 강화 메뉴)
├── [게임 시작] 버튼 + 스태미나 표시
├── 상단: 코인 / 젬 / 유저명
├── 하단 탭바
│   ├── 🏠 홈 (로비)
│   ├── 🗺️ 스테이지
│   ├── 💬 채팅 (전체/귓말)
│   ├── 🛒 상점
│   └── 👤 프로필 (랭킹/업적/친구)
│
인게임 화면
├── 상단: 스테이지 번호 / 콤보 / 하트(HP)
├── 중앙: 달리는 캐릭터 + 다가오는 벽
│   └── 벽 접근 시: 캐릭터 주먹 발광 + 배경 붉어짐 (거리 힌트)
│   └── 타이밍 바 없음 — 거리 감각으로 직접 판정
├── 판정 표시: PERFECT! / GREAT / GOOD / MISS (터치 직후 표시)
└── 하단: 스킬 버튼 3개 + 스킬 게이지
│
게임오버 화면
├── 결과 (스테이지 / 콤보 / 획득 코인)
├── [광고 보고 부활] 버튼
└── [결과 확인] → 보상 수령 → 로비
```

## 17. 백엔드 API 설계 (주요)

```
[인증]
POST /api/game/auth/register     → 닉네임 등록
POST /api/game/auth/login        → 디바이스 ID 기반 로그인

[게임 데이터]
GET  /api/game/user/me           → 내 스탯/강화 정보
POST /api/game/result            → 게임 결과 저장 (스테이지, 콤보, 코인)
GET  /api/game/ranking/stage     → 스테이지 랭킹
GET  /api/game/ranking/combo     → 콤보 랭킹

[채팅]
WS   /ws/chat/global             → 전체 채팅 웹소켓
WS   /ws/chat/dm/{userId}        → 귓말 웹소켓
GET  /api/game/chat/history      → 최근 채팅 100개

[친구]
POST /api/game/friends/request   → 친구 신청
POST /api/game/friends/accept    → 친구 수락
GET  /api/game/friends/list      → 친구 목록

[상점/과금]
POST /api/game/purchase/verify   → 구매 영수증 검증
GET  /api/game/shop/items        → 상점 아이템 목록
POST /api/game/gacha/pull        → 가챠 실행
```
